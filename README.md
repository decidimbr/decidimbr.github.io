# Decidim Brasil · Diretório

Diretório de módulos, implantações e pesquisas do Decidim no Brasil, ponto de partida do Capítulo Brasil da [Associação Decidim](https://decidim.org), em formação.

Site estático publicado com GitHub Pages: `index.html` e dados em `data/*.json`. Não há etapa de build.

- Para incluir um módulo ou implantação, veja [CONTRIBUTING.md](CONTRIBUTING.md).
- Para ver localmente: `python3 -m http.server 8000` e abra <http://localhost:8000>.
